# Звіт до лабораторної роботи № 1

## 1. Тема, номер і варіант
- Предметна область: спортивна ліга
- Номер варіанта: 17
- Операційна система: Windows 11

## 2. Мета роботи
Створити першу версію консольної програми на Java, яка читає записи з CSV-файлу,
перевіряє їх, обчислює показники та формує звіт у консоль і у файл.
Налаштувати Maven-проєкт зі стандартною структурою та Maven Wrapper.

## 3. Постановка задачі
Формат запису: `home:String; away:String; homeScore:int; awayScore:int; attendance:int`.

Показники:
1. кількість коректних записів;
2. середня кількість голів за матч (`homeScore + awayScore`);
3. найбільша відвідуваність;
4. сумарна відвідуваність.

## 4. Структура програми
- `src/main/java/ua/lpnu/kzp/setup/Main.java`: уся логіка програми.
- `data/input.csv`: вхідні дані (3 коректні та 2 хибні рядки).
- `out/report.txt`: файл звіту, який створює програма.

Потік даних: аргументи → читання файлу → розбір кожного рядка (`split`) →
перевірка кількості полів → перетворення чисел → перевірка на від'ємні значення →
накопичення показників → формування звіту → вивід у консоль і запис у файл.

## 7. Приклади роботи
Вхідні дані:
```text
Карпати;Шахтар;2;1;15000
Динамо;Зоря;0;0;8200
Дніпро;Полісся;3;2;12400
Верес;Колос;абв;1;5000
Рух;Чорноморець;1;-2;7000
```

Вивід у консоль і вміст `out/report.txt`:
```text
Коректних записів: 3
Середня кількість голів: 2.67
Найбільша відвідуваність: 15000
Сумарна відвідуваність: 35600
Помилок: 2
Рядок 4: числове поле має помилковий формат
Рядок 5: від'ємне числове значення
```
