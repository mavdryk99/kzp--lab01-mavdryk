# Звіт до лабораторної роботи № 1

## 1. Тема, номер і варіант
- Предметна область: спортивна ліга
- Номер варіанта: 17
- Операційна система: Windows 11

## 2. Мета роботи
Створити першу версію консольної програми на Java, яка читає записи з CSV-файлу,
перевіряє їх, обчислює показники та формує звіт у консоль і у файл.
Налаштувати Maven-проєкт зі стандартною структурою та Maven Wrapper.

## 3. Постановка задачі
Формат запису: `home:String; away:String; homeScore:int; awayScore:int; attendance:int`.

Показники:
1. кількість коректних записів;
2. середня кількість голів за матч (`homeScore + awayScore`);
3. найбільша відвідуваність;
4. сумарна відвідуваність.

## 4. Структура програми
- `src/main/java/ua/lpnu/kzp/setup/Main.java`: уся логіка програми.
- `data/input.csv`: вхідні дані (3 коректні та 2 хибні рядки).
- `out/report.txt`: файл звіту, який створює програма.

Потік даних: аргументи → читання файлу → розбір кожного рядка (`split`) →
перевірка кількості полів → перетворення чисел → перевірка на від'ємні значення →
накопичення показників → формування звіту → вивід у консоль і запис у файл.

## 5. Інфраструктура
- JDK 25 (Temurin), `maven.compiler.release` = 21.
- Maven 3.9.16 (глобально) і Maven Wrapper 3.9.11 у проєкті.
- `pom.xml`: Compiler Plugin 3.13.0, кодування UTF-8; збірка командою `mvnw clean compile`.

## 11. Відповіді на контрольні питання
1. pom.xml це файл у якому описано структуру проєкту та його налаштування.
2. `test` запускає модульні тести. `package` компілює, тестує та пакує код у Jar. 
`verify`проходить усі попередні фази та виконує додаткові перевірки.
3. Maven wrapper: запускає maven без його встановлення на комп'ютер.
4. метод main єдина точка входу для запуску Java програм.
5. примітивний тип зберігає саму величину, а String це клас, зміна якого посилається на об'єкт із даними.
6. щоб зберегти точність розрахунків, бо тип int не виводить дробові числа. (приклад: `int` 5/2 = `double` 2.5)
7. Integer.parseInt кидає виняток NumberFormatException, бо рядок abc неможливо перетворити в ціле число, якщо не перехопити виняток то програма впаде. Для обробки винятків використовую `try/catch`.
8. Можливе неточне виконання, програма рахує результати без цього значення, просто мовчки пропускає його.
9. String.split(";", -1) зберігає порожнє останнє поле в масиві.
10. Path.of це кросплатформений засіб, допомагає запобігти помилок з екрануванням шляхів.
11. StandardCharsets.UTF_8 гарантує однакове зчитування та запис тексту на будь-якій ОС.
12. %n визначає яке переведенн рядка потрібне для конкретної ОС. \n завжди означає один символ LF та не залежить від ОС. 
13. кількість голів; що `homeScore`, `awayScore` і `attendance` це цілі числа; що ці числа не від'ємні; що `home` та `away` не порожні. 
14. два записи з непарною сумою голів; порожній набір даних; набір з хибними рядками.
15. статичний аналізатор шукає помилку в самому коді, читає скомпільований код без запуску програми. Запускається у фазі `verify`
16. GitHub Actions автоматично запускає збірку, тести та перевірки на серверах GitHub. публікує JAR як артефакт, доводить кросплатформіність.
