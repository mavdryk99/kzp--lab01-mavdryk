# КЗП: Java-лабораторні роботи

## Лабораторна робота № 2: класи, record і інкапсуляція

### Призначення

Консольна програма читає записи про проживання гостей у готелі з CSV-файлу,
перевіряє їх, обчислює чотири показники та виводить звіт у консоль і у файл.
У цій роботі рядкові записи замінено класом `Booking`, а підсумок описано
через record `BookingSummary`. Зовнішній формат звіту не змінюється.

### Формат входу

Файл у кодуванні UTF-8, один запис у рядку, поля розділено крапкою з комою:

```text
room;guest;nights;nightlyRate;category
```

| Поле | Тип | Опис |
|---|---|---|
| room | ціле число | номер кімнати |
| guest | текст | ім'я гостя |
| nights | ціле число | кількість ночей |
| nightlyRate | дробове число | тариф за ніч |
| category | текст | категорія номера |

Приклад (`data/input.csv`):

```text
101;Іваненко Олег;3;1200.00;Стандарт
205;Петренко Марія;5;2100.50;Люкс
310;Коваль Ігор;2;1500.00;Напівлюкс
412;Бондар Софія;abc;1800.00;Люкс
115;;4;1000.00;Стандарт
```

Останні два рядки хибні: нечислове поле та порожнє ім'я гостя.

### Структура класів

- `Booking`: клас-сутність із приватними незмінними полями; конструктор перевіряє всі правила; статичний метод `fromCsv` створює об'єкт із рядка CSV.
- `BookingSummary`: record з підсумком (кількість записів, сумарні ночі, виторг, найдовше проживання).
- `Main`: читає файл, створює об'єкти, формує та виводить звіт.

### Правила валідації

- ім'я гостя і категорія не `null` і не порожні;
- номер кімнати та кількість ночей не від'ємні;
- тариф не від'ємний і є скінченним числом;
- у рядку рівно 5 полів, числові поля мають коректний формат.

### Показники

1. Кількість коректних записів.
2. Сумарна кількість ночей.
3. Загальний виторг (ночі × тариф за ніч).
4. Найдовше проживання.

### Збірка та запуск

Windows (PowerShell):

```text
.\mvnw.cmd clean compile
java -cp target/classes ua.lpnu.kzp.setup.Main
```

macOS та Ubuntu:

```text
./mvnw clean compile
java -cp target/classes ua.lpnu.kzp.setup.Main
```

| Аргумент | Призначення |
|---|---|
| `--help` | показати підказку |
| `--input <файл>` | вхідний файл (за замовчуванням `data/input.csv`) |
| `--output <файл>` | файл звіту (за замовчуванням `out/report.txt`) |
