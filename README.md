# Лабораторна робота № 1: обробка записів спортивної ліги

## Призначення

Консольна програма на Java читає записи про матчі з CSV-файлу, перевіряє їх,
обчислює чотири показники та виводить звіт у консоль і у текстовий файл.
Хибні рядки не зупиняють програму: для кожного виводиться номер рядка та причина пропуску.

## Формат входу

Файл у кодуванні UTF-8, один матч у рядку, поля розділено крапкою з комою:

```text
home;away;homeScore;awayScore;attendance
```

| Поле | Тип | Опис |
|---|---|---|
| home | текст | команда-господар |
| away | текст | команда-гість |
| homeScore | ціле число | голи господарів |
| awayScore | ціле число | голи гостей |
| attendance | ціле число | кількість глядачів |

Приклад (`data/input.csv`):

```text
Карпати;Шахтар;2;1;15000
Динамо;Зоря;0;0;8200
Дніпро;Полісся;3;2;12400
Верес;Колос;абв;1;5000
Рух;Чорноморець;1;-2;7000
```

Останні два рядки хибні: нечислове поле та від'ємне значення.

## Показники

1. Кількість коректних записів.
2. Середня кількість голів за матч (`homeScore + awayScore`).
3. Найбільша відвідуваність.
4. Сумарна відвідуваність.

## Збірка та запуск

Windows (PowerShell):

```text
.\mvnw.cmd clean compile
java -cp target/classes ua.lpnu.kzp.setup.Main
```

macOS та Ubuntu:

```text
./mvnw clean compile
java -cp target/classes ua.lpnu.kzp.setup.Main
```

Аргументи командного рядка:

| Аргумент | Призначення |
|---|---|
| `--help` | показати підказку |
| `--input <файл>` | вхідний файл (за замовчуванням `data/input.csv`) |
| `--output <файл>` | файл звіту (за замовчуванням `out/report.txt`) |

Приклад:

```text
java -cp target/classes ua.lpnu.kzp.setup.Main --input data/input.csv --output out/report.txt
```
