## Лабораторна робота № 3: спадкування, enum і поліморфізм

### Призначення

Програма читає записи про проживання в готелі, створює об'єкти двох підтипів,
обчислює вартість проживання поліморфним методом і виводить звіт у консоль і у файл.

### Ієрархія класів

- `Booking`: абстрактний базовий тип зі спільними полями й перевіркою, метод `stayCost()` без тіла.
- `StandardBooking`: вартість = ночі × тариф.
- `PremiumBooking`: вартість = ночі × (тариф + 200 грн сервісу за ніч).
- `RoomKind`: enum категорій (`STANDARD`, `SEMI_LUX`, `LUX`) з підписом і ознакою преміальності.
- `BookingSummary`: record з підсумком.

Підтип вибирає `Booking.fromCsv` за категорією: «Стандарт» дає `StandardBooking`,
«Напівлюкс» і «Люкс» дають `PremiumBooking`. Формат CSV не змінився:

```text
room;guest;nights;nightlyRate;category
```

### Приклад

```text
101;Іваненко Олег;3;1200.00;Стандарт
205;Петренко Марія;5;2100.50;Люкс
310;Коваль Ігор;2;1500.00;Напівлюкс
412;Бондар Софія;abc;1800.00;Люкс
115;;4;1000.00;Стандарт
220;Мельник Ірина;2;1400.00;Президентський
```

Вивід:

```text
Коректних записів: 3
Сумарна кількість ночей: 10
Загальний виторг: 18502.50
Найдовше проживання: 5
Помилок: 3
Рядок 4: Числове поле має помилковий формат
Рядок 5: Ім'я гостя не може бути порожнім
Рядок 6: Невідома категорія номера: Президентський
```
